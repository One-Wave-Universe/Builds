## What this folder is not

This folder does **not** contain CELL_V1 memory and does **not** contain software weights that substitute for the physical body.

Memory in the proposed CELL_V1 architecture is the retained lean / hysteretic state in the physical path.

Zer0 may describe, route, compare, and rebase state, but it must not claim that a stored software value remembers for the body.
