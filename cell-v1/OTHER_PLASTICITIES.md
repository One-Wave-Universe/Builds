## The others

### Synaptic tag and capture (Frey / Morris)

Weak write makes a *local tag* (no new protein). Strong write nearby makes diffusible PRPs. Tag captures PRPs → weak trace lives. Spacing / novelty around a weak event rescues it. Tag ≠ LTP expression; they can split.

CELL slot: P6 on shared square figure-8. Strong seat's leftover field is the only legal “PRP”. Weak seat must not persist if the strong write is on a different body.

### Behavioral tagging / spacing

Same idea at behavior: novelty minutes around a weak encoding keeps it. CELL: two writes separated by measured leftover-field time, not by a clock chip. If the window is only “we waited 20 minutes on a phone,” that is not the fixture.

### Intrinsic plasticity (LTP-IE / homeostatic excitability)

The cable changes spike-ability: Na, K, I_h, AHP. Fast tetanus can raise excitability; long deprivation can raise it homeostatically; local dendritic channel edits change integration.

CELL slot: threshold of the *pair* after a history, with the nucleus held constant. If only the core Br changed, that is path memory. If the FET/amp offset or winding magnetics changed the crossing without Br change, that is intrinsic-class. Measure both. Do not add a digital gain knob.

### Synaptic scaling (Turrigiano)

Hours/days, all synapses up or down together after chronic silence or roar. Too slow to stop a seconds-scale Hebb runaway by itself.

CELL slot: long idle at low V_BUS vs long high rail, then the same probe on *all* seats. If every seat moves the same way, scaling-class. Distinct from P2 (one seat's fence).

### Heterosynaptic LTP/LTD

A write at synapse A changes neighbor B with no pre on B. Often weight-dependent. Can compete. Discovered before homosynaptic LTD.

CELL slot: write seat A, probe untouched seat B on the same body. If B moves, heterosynaptic analogue. Quote how far (one shared core vs next cell).

### Inhibitory plasticity (I→E, E→I)

Inhibition is plastic. Helps balance. Heterosynaptic terms on interneurons proposed as the brake.

CELL slot: there is no second species yet. Do not invent a digital I-cell. Closest analogue is an opposed winding that *subtracts* flux. Two-of-three / physical sum in BREADBOARD is the candidate, not a NAND.

### Neuromodulator pull-push (Gs vs Gq)

Same Ca, LTP-only or LTD-only landscape.

CELL slot: bus height + lactate-bus / chemistry if that file ever earns a receipt. Until then, V_BUS high vs low during an otherwise identical write. If sign of retained lean flips with rail only, pull-push analogue. Still not a mode bit.

### Dendritic locality

Tag-and-capture fails across branches. Plasticity can be branch-specific.

CELL slot: two nuclei that only share V_BUS, not a core. If tag jumps the bus, locality failed (or you built a global smear).

### Co-dependent E/I

Recent models: inhibition gates excitatory write; neighbors set LTP size; heterosynaptic E² term stops runaway.

CELL slot: physical summing of aligned vs opposed flux. Measure 2-on-1, 1-on-2. No majority gate IC.
