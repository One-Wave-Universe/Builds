## M4 routing/brain geometry
- M4 is a dedicated routing/connection cell role.
- Its brain/nucleus is the opposed pyramidal/tapered wedge pair.
- **Inside one cell: TIP ⇄ TIP.** Opposed narrow tips converge at the center, providing the proposed convergence/compression and local comparison/balance/resolution interface.
- **Between cells: BASE ⇄ BASE.** Broad faces provide the proposed bidirectional intercell routing/distribution interface.
- The full bidirectional path is **BASE ⇄ TIP ⇄ TIP ⇄ BASE**. Convergence and outward expression coexist; this is not a one-way pipeline.
- Exact electrical/magnetic interface implementation remains OPEN / BENCH TEST.

## Cell roles
- Center motor/control cell: square two-aperture figure-eight hysteretic nucleus.
- Six surrounding sensor cells: round two-aperture figure-eight hysteretic nuclei.
- M4 routing cell: opposed pyramidal nucleus.
- M5: double pentagonal nucleus.
- M6: double hexagonal nucleus.

## Outer/body field
Two plain round outer/body toroids form the common body differential interface. Proposed relationship:

**FIELD outer toroid ⇄ center nucleus/brain ⇄ VOID outer toroid**

Their opposed arrangement is a proposed Helmholtz-like coupling. Coupled cells may produce a larger distributed magnetic field. This is a hypothesis requiring measurement.

## Computing/state model
Binary establishes FIELD/VOID opposition; ternary expresses + / 0 / − around CENTER; quadratic is the coupled relationship of the two opposed loops carrying the binary and ternary relationships together, with hysteresis supplying history.

## Distributed regulation and memory
The technical term for the local body function is **distributed closed-loop regulation with local state and resource arbitration**: cells process local differentials, regulate reinjection, request power when needed, and report excessive strain/load or selected limits.

Short-term = transient state. Mid-term = local energy/gating hysteresis remembering recent input, useful action, loss and reinjection. Long-term = shared domain-wall hysteretic body/path memory. Muscle memory is a shared body state, not isolated single-cell memory.

Initial domain-wall material candidate: patterned soft-magnetic permalloy, approximately Ni80Fe20; exact material, thickness and patterning remain experimental.

## Functional-path constraint
No resistors in the intended CELL functional path for state, gating, balancing, reinjection or computation. External bench/protection/indicator resistors are separate from the intended mechanism.
