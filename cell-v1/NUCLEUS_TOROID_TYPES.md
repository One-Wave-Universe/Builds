# Nucleus and toroid types

**Status:** Current Build-repo geometry authority for cell-role magnetic cores.

The electrical / state-machine rules can recur across cell roles, but the magnetic core geometry is **not universal**.

| Cell role | Nucleus / brain core | Outer toroids | Current geometry |
| --- | --- | --- | --- |
| Sensor cell | Round figure-8 toroid | role-dependent | planar / 2D |
| Motor-control cell | Square figure-8 toroid | role-dependent | planar / 2D |
| M4 cell | Two triangular toroidal loops base-to-base | Two plain round toroids | planar / 2D |
| Five-mind cell | Double pentagon toroidal geometry | open | planar / 2D |
| Six-mind cell | Double hexagon toroidal geometry | open | planar / 2D |

## M4 correction

The M4 outer field pair is:

```text
plain round toroid  <->  M4 double-triangle nucleus  <->  plain round toroid
```

The two M4 outer toroids are **not figure-8 toroids**.

## Sensor correction

The **round figure-8** belongs to the **sensor-cell nucleus** as the current simple binary / differential sensing brain geometry.

## Motor-control correction

The **square figure-8** belongs to the **motor-control-cell nucleus** where the core must align to the grid / lattice connection.

## Higher-mind nuclei

- M4: double triangle, base-to-base.
- Five-mind: double pentagon.
- Six-mind: double hexagon.

## Dimensional rule

All current core hardware is **2D / planar**. The magnetic fields generated by these cores are inherently **3D**.

## Anti-drift

Do not:
- make square figure-8 universal;
- make round figure-8 universal;
- call the M4 outer round toroids figure-8s;
- substitute M4, five-mind, or six-mind nucleus geometry merely from polygon count without preserving the paired toroidal form;
- confuse nucleus geometry with CENTER or V_BUS;
- claim field strength, hysteresis, coupling, torque, retention, or efficiency without measurement.
