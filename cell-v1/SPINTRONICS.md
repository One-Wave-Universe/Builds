# Spintronics = actions down

Lower window of the 8. Drive. Write. Not a second brain.

Charge current in the under lattice already is the write. Spintronics is *how* that current torques the magnetic layer instead of only heating it.

## Map

| Action | Spin / magnet |
| --- | --- |
| PUSH | current large enough to grow Br that way (STT / SOT damping-like) |
| PULL | smaller current, back toward home / minor loop |
| FLIP | current that beats Hc the other way |
| PASS | no write current; HOLD; regen to V_BUS |

Views stay up: figure-8 / inductive / later TMR *reads* Br. Write path and read path can split (SOT three-terminal is exactly that — write in the heavy-metal strip under the magnet, read elsewhere). That matches top sense / bottom act.

## What we use when

**Now:** current in copper + ferrite/Permalloy foil. Oersted field + ordinary H = NI/ℓ. That *is* already a write. No cleanroom.

**Later actions-down:** Permalloy or CoFeB on a heavy-metal understrip (Ta, W, Pt). Lattice current → spin current → torque on Br. Same PERMIT, same two-of-three. Smaller current for the same flip if SOT is efficient.

Do not replace the cell with an MTJ crossbar ANN. Do not put sixteen MTJs in for the 4×4. The 16 are still view×action on one 8.
