# Reinjection bus / vagus circulation

## Reinjection starts at cluster scale

A single isolated CELL_V1 does **not** require a full reinjection circulation.

At single-cell scale, the cell needs:

- its differential A/B/C state,
- nucleus / hysteresis,
- local winding action,
- safe local recovery of inductive energy,
- and a defined return path.

That is local recovery, not yet the full vagus reinjection system.

The full reinjection loop becomes meaningful when multiple cells form a flower / body cluster and there is a **combined body state** to return and redistribute.

## Flower / body vagus circulation

At cluster scale the vagus system becomes a paired circulation:

- **arterial / feed side** distributes available energy and the current combined body / lattice condition outward;
- **venous / return side** collects recovered energy and physical consequences from many cells;
- **shared V_BUS / storage** integrates that return into the next live body state;
- the feed side then redistributes that updated state back into the lattice.

```
many cells
   ↓
local actions + local returns
   ↓
venous/return network
   ↓
shared V_BUS / combined body state
   ↓
arterial/feed network
   ↓
cells receive the updated shared condition
```

This is the architectural reinjection loop.

CENTER / virtual ground remains separate from both feed and return.

## Why this matters

The cluster loop gives reinjection something that a lone cell does not have: **a combined state worth feeding back**.

That combined state can contain contributions from:

- multiple differential leans,
- multiple retained magnetic states,
- multiple winding events,
- load / strain across the flower,
- recovered energy,
- neighbor interactions.

The next cell decision can therefore be biased by what the larger body just did, rather than only by that cell's own local history.

This is the proposed physical basis for body-scale retained behavior / “muscle memory.”

## Engineering distinction

- **Single cell:** local hysteresis + local recovery.
- **Flower / body cluster:** shared return + combined state + redistribution = reinjection.
- **Muscle memory:** proposed distributed retained bias of that larger coupled loop.

Do not force a closed artery/vein reinjection loop into the one-cell drawing just to preserve the analogy.

## Build order

1. Validate one cell's differential behavior.
2. Validate one cell's local hysteresis.
3. Validate one cell's safe energy recovery.
4. Build multiple cells into a flower.
5. Measure their combined return.
6. Form a shared V_BUS / body state.
7. Feed that state back through a shared feed network.
8. Test whether repeated cluster patterns create reproducible retained bias.
9. Only then use stronger muscle-memory language.

## Status

Established mechanisms:
- local hysteresis,
- inductive recovery,
- supply / return networks,
- distributed coupled circuits.

Hypothesis until measured:
- useful body-scale state integration,
- stable reinjection across a flower,
- useful distributed retained bias,
- body-pattern reinforcement resembling muscle memory.
