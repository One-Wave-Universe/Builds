# DC / AC / RC

They did not get thrown out. They go **up**, as field and void.

Not three power supplies. Three kinds of current in the same path. All analog. No comparator sorts them.

| Kind | What it is | Which way is up |
| --- | --- | --- |
| **DC** | Committed flow. Axis left the wobble. Net current one way. The lean as a stand. At lattice scale, the brain reinjection loop. | **Void.** |
| **AC** | Drive across the dead zone. The excursion that tries to leave HOME. The turn. | **Field rotation.** |
| **Mirrored DC** | The same stand, flipped. AC rides with it. | The mirror of void, still up. |
| **RC** | What remains after the event. Not a third rail. | Goes up with them. |

---

## Two uses of DC — do not mash

**Local DC** is the committed lean on one axis. `D` left the wobble. Net current one way. Void stand. Mirrored DC is that stand flipped.

**Lattice DC** is the brain reinjection loop. It is the closed return that connected cells share. Recoverable consequence comes back through that loop and revisits the shared hysteretic layer. That layer is the muscle memory. Repeated traversal biases the path. The next event does not start from a blank body.

```text
local event
  -> committed DC lean
  -> AC excursion / rotation
  -> collapse
  -> lattice DC reinjection loop
       energy rail = V_BUS
       memory = shared hysteresis layer across connected cells
  -> next event meets the biased path
```

V_BUS is the energy reservoir of that loop. V_BUS voltage alone is not the muscle memory.

The shared hysteretic / domain-wall layer is the muscle memory. It follows connected-cell edges. It is not CENTER. It is not the Helmholtz weather. Helmholtz, if built, is uniform bias. Scars stay in the hysteresis layer.

RC is still what the round figure-8 holds after the event. Calling V_BUS "RC" mashes dump and hold. Calling the hysteresis layer "V_BUS" mashes memory and rail.

## Where they sit

- The **round figure-8 toroid** is the differential / ternary side. Local DC, AC, and the mirrored DC live there.
- Collapse still goes through the **square figure-8** onto the lattice DC loop. That current is the write into the shared hysteresis layer, with recoverable energy steered to V_BUS.
- RC is what the round toroid still holds after the event.

## One event

1. HOLD (no net local DC, tail on).
2. AC drive. Field rotates. D walks.
3. Two-of-three: local DC commits (void) or you fall back to HOLD. The mirror is the other way.
4. Collapse enters the lattice DC reinjection loop. Energy toward V_BUS. The return revisits and may bias the shared hysteresis layer. That retained path is muscle memory for connected cells.
5. RC left on the round toroid.

Next event sees RC as the new home offset and the shared layer as the body it has to cross. Use deepens. Disuse fades.
