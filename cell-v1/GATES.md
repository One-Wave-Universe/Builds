# Both ways

**Both readings are on.**

- Three axes A B C — each bidirectional.
- Three gates on an axis CHOICE → PIVOT → FLIP — each bidirectional.
- Last action down = FLIP, one pair reversed. Not extra invert hardware.

Same silicon both directions. Body diodes cancelled (back-to-back) or isolated-body later.

Never both directions ON at once. GAP is that.
