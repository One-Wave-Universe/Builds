# Hex lattice (bus side)

The under hex **mesh** is the hysteresis lattice. Shared edges of the tiling. That metal is V_BUS *and* the long trace.

```
  top: pairs + CENTER + figure-8 (read home)
  mid: heavy-metal strip (write torque)
  under hex: copper + magnetic skin along every edge → V_BUS + Br
```

Each hex edge is a segment of the group memory. Neighbor flowers share an edge → they share that segment of Br. That is why the trace is group muscle, not a private core in each cell.

Figure-8 does not replace this mesh. Figure-8 reads CENTER, which sits in the field of the mesh. Mesh holds. 8 reads. Strip writes. Cap on the rail is the short echo.

Clockwise edges still A+ B+ C+ A- B- C-. Those edges *are* the lattice traces.
