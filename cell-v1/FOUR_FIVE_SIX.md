# Four, five, six

After two choices and three moves. Same analog algorithm. Not a second machine.

Canon already names these in `algorithms/FOUR_BRANCHES_AND_UNIVERSAL_RULES.md`. This file is the cell reading.

Level flow:

```text
REFERENCE → POLARITY → MOVE → VIEWS/ACTIONS → STATE/SCALE → RECURSE → REFERENCE
```

On the cell that is CENTER, FIELD/VOID, A/B/C, then the four/five/six below.

## 4 views up, 4 actions down

Old state expresses actions down. New state returns views up. Both ride the same loop around CENTER. Not a read-erase-calculate-write cycle.

Views up, Field L4:

```text
REFERENCE, CHANGE, DIRECTION, RESULT
```

Actions down, Void L4:

```text
PULL, PUSH, FLIP, PASS
```

Four and four. The next view is the last move plus what came back up the lattice DC loop.

PASS is toward the bus, not onto CENTER. FLIP is the completed three-mirror loop, not a clock edge. PUSH and PULL are the opposed seats of a differential. They are not extra axes.

## 5 states and 5 scale

State is where the event is in its own life. Scale is how far the coupled body reaches. Not the same ladder. Not A/B/C.

States, Field L5:

```text
IDLE, PRIMED, EXECUTING, VECTORING, RESOLVING
```

Scale, Void L5:

```text
MICRO, SMALL, MIDDLE, LARGE, MACRO
```

Hardware reading of that scale, still five, still not a rename of the axes:

```text
cell → cube → Rubik → two Rubiks → the body they make
```

POINT / PATH / FIELD stay scale language. They are not aliases for A, B, C.

## 6 nested recursive

Six is the nested loop, not a sixth move.

Field recursive loop:

```text
BEGIN, BUILD, HOLD, EXTEND, RESOLVE, RETURN
```

Void mirror loop:

```text
RECEIVE, PREPARE, RESERVE, OFFER, VALIDATE, RESTORE
```

Each higher level keeps the lower ones. `1 ⊂ 2 ⊂ 3 ⊂ 4 ⊂ 5 ⊂ 6`.

On the iron, six is also the hex: six wedges, six windings, tip-to-tip inside, base-to-base between. The square figure-8 is only the middle controller nucleus. The ring keeps round figure-8 nuclei. Nested recursion is the loop those cells run. It is not six stacked hysteresis films. Phase I still has one shared hysteresis layer. Add a memory scale only when one layer cannot keep two habits.

## Do not mash

- 2 choices = FIELD / VOID.
- 3 moves = A / B / C, the lean.
- 4/4 = views up / actions down.
- 5/5 = state / scale.
- 6 = nested recursion, and the hex that carries it.
- 7 = the two systems combined. Six sensor cells plus one motor-control cell. See `cell-v1/SEVEN.md`. Not seven bands.
- Lattice DC returns the action into the shared hysteresis layer. The view that comes back is what the next loop calls old.

Same iron. No interpreter beside it.
