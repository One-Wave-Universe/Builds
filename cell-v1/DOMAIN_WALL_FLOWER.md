## Flower

Seven hexes. One motor middle (square figure-8 nucleus). Six sensors (round figure-8 nuclei). Every cell wears the same two plain-round Helmholtz-like body rings.

Letters are **edges**, not corners.

```text
middle A+  kisses  neighbor A-
middle B+  kisses  neighbor B-
middle C+  kisses  neighbor C-
```

Twelve shared sides. The domain-wall layer follows those sides so the path is continuous under the kisses.

## What a domain wall is here

Gray: in a soft ferromagnet (permalloy Ni80Fe20 candidate) two domains meet at a wall. The wall is the bit / the groove. Current or field moves the wall. Remanence keeps it when drive is gone.

CELL: the wall is not a racetrack register. It is the **groove the flower already walked**. Repeated consensus writes deepen it. Disuse / heat / opposite practice moves it back.

Local nucleus Br = this cell's last lean.
Sheet wall pattern = body's habit across all seven.

FIELD (nucleus flip) writes VOID (sheet). VOID biases the next FIELD flip.

## Write across the whole flower

No supervisor. No poll. No clock.

1. A cell leaves HOLD. Nucleus fires. Local Br set.
2. Coupling into the sheet under that cell / that shared edge moves or pins a wall.
3. Because the edge is shared metal, the neighbor's under-layer already has that perturbation.
4. Reinjection returns energy to V_BUS. The next traversal of any cell on that path meets the biased sheet.
5. Practice deepens the same route. First-habit freeze is a fail (need fade / opposite write).

All connected cells are the distributed intelligence because they sit on **one** sheet, not because they message.

Phase-I: **one** domain-wall layer for the whole flower. Do not stack finger/hand/limb sheets until this one is measured.

## Must measure before claiming muscle memory

- Br after repeated route use
- path localized vs smeared across all twelve sides
- neighbor crosstalk
- retention / decay τ
- same route needs less drive after practice
- opposite practice rewrites
- next motor decision biased without CENTER corruption
- effect survives V_BUS sag (proves it is not the rail)

Fail: sheet is one global smear, or only the writing cell changed, or only V_BUS moved.
