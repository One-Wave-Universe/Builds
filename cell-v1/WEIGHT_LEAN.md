# WEIGHT = LEAN

A weight is not a number. A weight is a physical lean off a moving reference.

Not a table entry. Not a backprop parameter. A measurable asymmetric departure from a floating virtual ground. The weight is the lean. The lean is the weight.

Status: structurally locked. Not measured. Hardware score stays 0% until Cell-0 LOG.md has voltages and the Section 22 probe passes.

This is Builds / cell law. Not a Science cosmology claim.

## Reference

Virtual ground, floating. Not a fixed rail. It carries the history of prior leans.

That is the analog form of T6 REBASE: the last settled whole becomes the next center.

## Three properties of a lean

- **Direction** — plus or minus relative to center. Sign of the weight. Maps to DOWN / UP.
- **Magnitude** — how far off center. Strength of the weight.
- **Hardness** — how hard the system resists being pushed back to center. Persistence of the weight.

## Circuit

Subthreshold differential pair. Two matched MOSFETs sharing a tail current.

- Tail current `Iss` = hardness
- Gate difference `Vd` = direction + magnitude

```
Idiff = Iss · tanh(Vd / (2 · n · Vt))
```

Cell-0 (9 V, 2N7000/BS170) is the first solderable pair. This 1 V band map is the analog-brain layer once a real subthreshold pair exists. Do not design Cell-0 around millivolts.

## Three states, not two

- **DOWN** — lean below center
- **HOLD** — balanced asymmetry, center band. Live tension. Tail current still flowing. gm still active. Not off.
- **UP** — lean above center

HOLD is the pocket.

## Learning

No separate training phase. Use deepens the lean. Disuse softens it.

- Repeat a path → lean hardens (consolidation)
- Path fails → lean softens or reverses
- Path unused → lean fades (decay)

Same event as doing. Muscle memory is not a metaphor here; it is the acceptance test.

### Hardness hierarchy

- Soft lean — labile, easy override, tonight's fill
- Hard lean — resists override, consolidated pocket
- Saturated lean — physically protected, bike-riding memory

Same core, same path, different write energy / tail current / dwell.

In Algorythm-Zer0 terms: `q` is the lean, `r` is hardness/retention, `g` is write gain from this use. Those numbers stay working calibration until a bench measures them.

## Why this is not a standard net

| Standard net | Lean system |
| --- | --- |
| Weights in one place, compute in another | Weight and compute are the same mechanism |
| Update via backprop | Update via use |
| Weights meaningless without architecture | Measure the lean, you know the behavior |
| Train then infer | Learning and doing are the same event |
| Copyable | The lean is history. The only way to get it is to live it |

## Scale

Same primitive at every level: lean off a moving ground.

- One cell — one lean, one decision
- One flower — seven leans coupled, center integrates six
- Brainstem — quadratic couplings, each with its own hardness
- Hemisphere — leans organized into paths
- Two hemispheres — two lean fields coupled

## Test (must pass before any grant claim of learning)

Identical probe. Different prior state. Different response.

If the lean measurably shifts with prior state, the mechanism holds. If not, rethink the model.

Until that number is in `LOG.md`, this page is proposed law, not measured hardware.
