# Android — Cell → Body → Cortex Work Map

## Scale ladder
CELL → SENSOR/MOTOR CELL ROLES → 7-CELL FLOWER → CLUSTER/LATTICE → BODY-STATE BUS → SENSORY CORTICES → MIND/DREAM MODEL → MOTOR CORTEX → BODY

Each scale must expose a compressed state/interface to the next scale rather than copying every lower-level signal upward.

## Body
First embodied target remains a simple mobile platform with wheels, speaker, binaural microphones, battery and local compute. More elaborate body/voice anatomy comes later.

## Sensory organization
Hearing proposal:
1 frequency decomposition
2 onset/timing/amplitude
3 binaural comparison/localization
4 feature representation
5 temporal/pattern representation

Vision proposal:
1 sensor/raw light
2 local contrast/center-surround-like transform
3 edge/orientation representation
4 contour/shape/motion relation
5 object/motion/state representation

These are engineering hypotheses inspired by biological organization, not claims that the android reproduces biological cortex.

## Internal/external loop
REAL WORLD sensors → sensory state → combined body/model state → action → REAL WORLD

SIMULATED DREAMSCAPE state → same sensory-compatible interfaces → internal model/action → simulated consequences → retained state

Dreaming should reuse the same cortex-facing interface as waking input so simulated and external experience can be compared without pretending they are identical sources.
