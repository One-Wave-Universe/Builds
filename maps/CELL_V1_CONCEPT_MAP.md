# CELL_V1 — Canonical Concept Map

Authority: `cell-v1/CELL_V1_2026-09-28_CORRECTION.md` plus later explicitly dated corrections.

## One cell
FIELD half ⇄ CENTER/reference/nucleus ⇄ VOID half

Three mirrored differential axes A/B/C surround the cell. Binary expresses FIELD/VOID opposition. Ternary expresses − / HOLD / + around CENTER. Quadratic/recursive state is the coupled relationship of the opposed loops plus retained history.

## Roles
- center motor/control cell: square two-aperture figure-eight hysteretic nucleus;
- six surrounding sensor cells: round two-aperture figure-eight hysteretic nuclei;
- M4 routing: opposed pyramidal/tapered nucleus, TIP⇄TIP internally and BASE⇄BASE between cells;
- M5: double pentagonal nucleus;
- M6: double hexagonal nucleus;
- two outer round toroids: common FIELD/VOID body differential interface.

## State and memory
TRANSIENT → local hysteresis → shared body/path hysteresis.
Local cells regulate state/resource/reinjection. Shared lattice represents collective body state. Only unresolved/excess conditions need propagate upward.

## Non-negotiable scientific boundary
This map is architecture intent, not proof that the integrated cell works. Geometry, thresholds, materials, coupling, reinjection and stability require bench validation.
