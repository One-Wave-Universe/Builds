## Reference law

Every participant receives the same evidence pack produced from
`One-Wave-Universe/One-Wave-Science`. External measurements must be acquired
and transformed by the Science repository's provenance-preserving data
pipelines before they are admitted as shared evidence. Provider responses do
not silently alter source numbers or the transform.

The visible dialogue is a critique loop: reference -> answer -> peer critique ->
re-reference -> convergence. A provider failure yields HOLD and preserves all
successful prior turns. No branch is called working until a live receipt proves
the intended providers returned.

## Portable boundary

Front ends own input/display only. The core owns request schema, actor order,
shared evidence identity, receipts and provider provenance. That boundary is
the future Linux program/Android app seam; neither UI gets a separate scientific
truth path.
